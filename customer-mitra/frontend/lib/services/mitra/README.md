# Mitra Services

Folder ini berisi service API yang khusus untuk fitur Mitra.

## File-file:
- `ride_service.dart` - Service untuk manajemen perjalanan/ride
- `vehicle_service.dart` - Service untuk manajemen kendaraan
- `verifikasi_service.dart` - Service untuk verifikasi mitra
- `withdrawal_service.dart` - Service untuk penarikan saldo mitra
