# Shared Services

Folder ini berisi service API yang digunakan bersama oleh Customer, Mitra, dan PosMitra.

## File-file:
- `api_config.dart` - Konfigurasi API (base URL, dll)
- `auth_service.dart` - Service untuk autentikasi (login, register, dll)
- `chat_service.dart` - Service untuk fitur chat
- `location_service.dart` - Service untuk lokasi dan maps
- `notification_api_service.dart` - Service API untuk notifikasi
- `notification_service.dart` - Service untuk manajemen notifikasi
- `phone_verification_service.dart` - Service untuk verifikasi nomor telepon
- `profile_service.dart` - Service untuk manajemen profil user
- `verification_service.dart` - Service untuk verifikasi umum
